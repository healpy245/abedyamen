Every tenant restaurant is taken from kaman.rest. Back office work then connects that restaurant id to three places.

  1. MFit Group billing id
  2. Kaman Agents id
  3. kaman-workspace.com, the main container
Restaurant No login here
kaman.rest The restaurant base. Every tenant starts from this id.
1 · MFit Group Invoice API: create and delete. Monthly payment API: items, price, and description.
2 · Kaman Agents Merge the code in and simplify it. Onboarding creates the restaurant in Workspace and links the MFit id and the kaman.rest id. The form needs that step.
3 · Workspace The main container. Support is already on this platform. Connect the API that creates a level 2 ticket.

What each worker opens

Support

  • Watch live devices and LAN health
  • Tickets, both levels
  • admin.kaman.rest, technical pages only

Agent

  • Leads
  • Invoices and monthly payment, through MFit
  • Paid features for the restaurant
  • The restaurant account on kaman.rest

Developer

  • Level 2 tickets
  • Watch live devices

Tester

  • Watch live devices
  • Check the release

Superadmin

  • Every door above
  • Turns a worker or a feature on or off
  • Names the lead of each team
